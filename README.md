# Bannerlord-Coop-Server

Arbeits-Repo für die automatisierte Installation und Verwaltung eines
**Mount & Blade II: Bannerlord** Coop-Dedicated-Servers.

Der Arbeitsauftrag steht noch aus — dieser Stand legt nur das Gerüst an.

## Verwandt

Das laufende Serverprojekt „calradia" liegt in `PlodyIce/Bannerlord-Coop`.

## Grundregel

Keine Secrets, keine Steam-Zugangsdaten, keine Savegames, Backups oder Logs
im Repo. Siehe `.gitignore`.
